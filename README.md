# BOWOW

BOWOW is a grant discovery prototype for nonprofits and student programs. It ranks illustrative funding opportunities, explains each match, and shows which filters partial matches miss.

## Run locally

From the repository root, run:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. No build or dependencies are required.

The grant catalog is sample data. Document selection stays in the browser and file contents are not analyzed.
